# 🕰️ v1 (legacy)

v1 is the first version of the prediction. It produced the model published as [`4math/FAB_Prediction_Model`](https://huggingface.co/4math/FAB_Prediction_Model). What is left of it in this repository:

| Path | What it is |
|---|---|
| `teklostudyv1.ipynb` | the card balance evaluator (expert scores per card) |
| `notebooks/gameplay_simulator.ipynb` | v1 simulation and training-data notebook |
| `simulation/` | v1 game engine and card database |
| `quick_demo.py` | v1 demo of the engine |

v1 also trained and served models on AWS SageMaker, with Terraform in `IaC/`, training scripts in `scripts/` and card-proposal tools that called SageMaker endpoints. The project now uses Hugging Face only, so that code has been removed. It remains in the git history.

## Why v2 exists

A review of v1 found that its prediction could not work:

| Part | Problem in v1 | v2 |
|---|---|---|
| Decks | 9 presets, and 5 of them were the same 20 cards: unknown preset names fell back to the first 20 cards of the database | 800 random decks, all different |
| Game engine | attack cards were never played from hand, items never entered play, defense was ignored | a small engine where cost, pitch, power, defense, Go again, Boost, items and Evos all matter |
| Game statistics | Evo counts and resources were set from hand-typed per-deck tables plus random noise | every number comes from the games |
| Features | game length, final life and consistency were measured from the games, so they leaked the answer | features come from the deck list only |
| Missing values | a missing card count was filled with the column average (a Nano deck "had" 3 AI cards) | a missing count is 0 |
| Score | cross-validated R² −1.33 on 9 rows, worse than guessing the average | cross-validated R² 0.67 on 646 training decks, 0.68 on 154 unseen ones |
| Published model | the model card's Quick Start passes 19 numbers to a model expecting 17, so it crashes; its `config.json` also lists the wrong feature names | the model takes named columns built by `teklo.deck_features` |

The v2 notebooks explain each fix step by step. Notebook 05 will replace the published model.
